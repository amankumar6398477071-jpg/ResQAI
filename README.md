\# ResQAI



\## AI-Powered Disaster Response \& Rescue Intelligence System



ResQAI is an AI-powered disaster response and rescue intelligence platform designed to help citizens, emergency responders, and authorities coordinate faster and make better decisions during disasters.



\## Core Modules



\- Citizen SOS and incident reporting

\- AI-powered incident analysis

\- Disaster priority classification

\- Rescue resource matching

\- GIS-based incident visualization

\- Authority response dashboard

\- Disaster data management
